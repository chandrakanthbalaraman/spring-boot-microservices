# Shared style — all slides in this pack

Paste the block below at the top of every GenerateImage prompt. Reference `docs/phases/reference/api-gateway/{N}.jpg` for slide N.

```
Create a 1:1 square educational carousel slide. Match the attached reference image closely in layout, density, and hand-drawn notebook style.

STYLE:
- Lined notebook paper, faint blue rules, spiral binding on the LEFT
- Marker + highlighter infographic (NOT dark mode, NOT neon, NOT Inter dashboard, NOT 3D glass)
- Yellow highlighter title bar; pink/lavender subtitle pill
- Top-left pill: "Slide N/10"
- Top-right handwritten: "SB-MS Interview Prep" — NO Instagram handles, never @java_interview_prep
- Pastel cards (blue / green / pink / yellow / lavender) with rounded corners and thin ink outlines
- Code in white rounded boxes with simple colored keywords
- Footer: floppy-disk + "Save before your interview !" and "SB-MS · Phase 02"
- Spell every English word correctly. Short labels, no overlapping cards.
```

Color-code clients: RestClient = blue, OpenFeign = green, WebClient = purple.

Banned on-slide: Eureka, API Gateway, Resilience4j, Kafka, Instagram handles.
